# 20-stage curriculum mapping

Each stage requires the preceding stage; instructors may adapt the pace. Each assessment is passed by an executable, explained result, not by copying output.

## 1. Introduction to ML
- Prerequisite: none
- Objective and concepts: problem/label/feature.
- Dataset: Both; libraries: Python, NumPy, pandas, Matplotlib, Seaborn, scikit-learn (as applicable).
- Exercise: produce a reproducible demonstration of problem/label/feature using the indicated data.
- Expected output and assessment: correct code, one justified result, interpretation, limitations.
- Common mistake to avoid: treating association as causation, misusing types, or leaking information into model development.

## Additional classical ML coverage
Classification: dummy, logistic, KNN, GaussianNB, tree, random forest, extra trees, SVC, LDA, QDA, gradient boosting, histogram boosting, AdaBoost, bagging. Regression: dummy, linear, ridge, lasso, elastic net, polynomial, trees, forests, extra trees, gradient boosting, histogram boosting, KNN, SVR. Choose compatible preprocessing and do not claim equal quality.
Unsupervised: KMeans, agglomerative, DBSCAN, GMM, PCA, ICA (only when justified), IsolationForest, LOF, OneClassSVM. Never input the supervised target into clustering.
Selection: stratified CV, TimeSeriesSplit, GridSearchCV, RandomizedSearchCV, learning and validation curves, feature selection, permutation importance, bias–variance, regularization, bootstraps and confidence intervals.
Evaluation: classification accuracy, balanced accuracy, precision, recall, specificity, F1, ROC-AUC, AP, calibration; regression MAE, MSE, RMSE, R², MAPE with zero-value caveat.
Advanced lessons: drift, monitoring, cost-sensitive learning, calibration, thresholds, ensemble methods, probability estimation, statistical inference and responsible AI. Basket association, recommender interactions and learning-to-rank require separate optional in-memory examples; they are not validly represented by these primary tables.

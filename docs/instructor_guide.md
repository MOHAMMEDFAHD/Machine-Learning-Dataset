# Instructor guide

Begin with the clean healthcare file for basic pandas and numerical examples, then raw healthcare for quality auditing. Keep `data/metadata/defect_manifest.csv` private until the exercise ends; it contains original values and displaced identities. The clean reference is not a legitimate imputation input in a real-world task. Compare solutions to reference data only for grading.

Use `pd.read_csv('data/clean/healthcare_clean.csv')`, `.info()`, `.dtypes`, `.describe(include='all')`, `.isna().mean()`, `.duplicated()`, `pd.to_numeric(errors='coerce')` and domain checks. Inspect and preserve legitimate extremes. Repair formatting deterministically, and never pretend a missing MNAR value is known. Use histograms for distributions, boxplots for extremes, countplots for category imbalance, scatterplots for relations, heatmaps for correlations, line plots for sales over time, and residual/confusion/ROC/PR/calibration plots for model diagnostics. Every plot needs a question and an interpretation.

Split before learning imputation, scaling, category encoding, feature selection or hyperparameters. One-hot encode nominal variables, preserve justified ordinal ordering; standardize scale-sensitive linear, distance and SVM models, but scaling is not generally necessary for trees. Fit all learned steps inside a pipeline on training folds. For healthcare stratify into 700/150/150, tune using train/CV and validation, and evaluate the test once. For retail split complete dates chronologically, build lag1 and backward rolling features by product, and do not shuffle. The one-day rolling-origin forecast can use yesterday's observed actual sales; multi-step forecasting needs recursive predictions or a different protocol.

Compare dummy baselines before logistic, ridge or trees; use ROC-AUC/PR, confusion matrices, sensitivity/specificity and calibration for classification; MAE/RMSE/R² and residual plots for regression. Consider false-negative versus false-positive costs, subgroup sample sizes and uncertainty. Report synthetic-only findings as Observation → Interpretation → Evidence → Uncertainty → Recommendation. Never claim real clinical or commercial validity.

To extend reproducibly, add a separately versioned optional generator with its own seed and tests; never append to the canonical 1,000-row CSVs. Re-run `python src/generate_datasets.py`, `python src/inject_defects.py`, `python src/validate_datasets.py`, `python -m pytest -q` and notebooks. The manifest records all injected changes; exact duplicate replacements deliberately displace two visible identities per raw file. Instructor must retain clean versions and manifest to reconstruct them.
